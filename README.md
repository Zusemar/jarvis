# Jarvis for Mac

Фоновый голосовой пульт для **настольного Spotify на Mac**. Без окон, веб-страниц, локального сервера и Spotify API-ключей. Произнесите «Джарвис, следующий» — Spotify переключит трек. Системная озвучка не требует Python; дополнительный локальный нейросетевой голос Kokoro использует отдельное окружение.

Mac воспроизводит музыку через подключенные колонки. iPhone и Windows для работы не требуются. Jarvis управляет Spotify на этом Mac; перед началом выберите в Spotify устройство воспроизведения «Этот компьютер».

## Первый запуск

Нужны macOS 13+ и установленный [Spotify](https://www.spotify.com/download/mac/). Для сборки — Apple Command Line Tools со Swift 5.9+ (`xcode-select --install`, если еще не установлены).

1. Дважды нажмите **«Собрать Jarvis.command»** в папке проекта или выполните `bash scripts/build-app.sh`.
2. Откройте полученный **`dist/Jarvis.app`**. При желании перенесите его в «Программы» **до первого запуска**, чтобы путь приложения не менялся.
3. Разрешите системные запросы: **Микрофон**, **Распознавание речи**, **управление Spotify**. Никакие настройки в Spotify Developer Dashboard не нужны.
4. В Spotify на Mac войдите в аккаунт, включите любой трек и выберите «Этот компьютер» как устройство вывода. Услышав «Джарвис готов», скажите **«Джарвис, пауза»**, затем **«Джарвис, продолжи»**.

У Jarvis нет окна, значка в Dock, меню в строке состояния и веб-интерфейса. macOS показывает системный индикатор микрофона. Ошибки запуска озвучиваются; технические сообщения доступны в приложении «Консоль» по `com.zusemar.jarvis`. Для команды loop нужен «Универсальный доступ» (Accessibility), чтобы выбрать штатный режим повтора одного трека в Spotify. Остальные команды не требуют этого разрешения; полный доступ к диску не нужен.

Чтобы завершить работу: **«Джарвис, перестань слушать»**. Если микрофон недоступен — завершите процесс Jarvis в «Мониторинге системы». Для повторного запуска снова откройте Jarvis.app.

## Команды

В каждой команде произносите «Джарвис». Можно сказать имя отдельно, затем в течение пяти секунд — одну команду.

| Скажите | Действие |
|---|---|
| Джарвис, пауза / стоп | Пауза |
| Джарвис, продолжи / включи музыку | Продолжить |
| Джарвис, следующий / предыдущий | Переключить трек |
| Джарвис, тише / громче | Изменить громкость Spotify на 5 пунктов |
| Джарвис, громкость сорок | Установить громкость 40 |
| Джарвис, сначала | Вернуть трек в начало |
| Джарвис, вперед на десять секунд | Перемотать вперед |
| Джарвис, назад на 20 секунд | Перемотать назад |
| Джарвис, включи / выключи перемешивание | Управление shuffle |
| Джарвис, включи / выключи повтор | Повтор текущей подборки |
| Джарвис, loop / луп | Включить повтор одного трека; повторная команда выключает |
| Джарвис, loop off / выключи луп | Выключить повтор трека |
| Джарвис, randomise / рандомайз | Включить случайный порядок; повторная команда выключает |
| Джарвис, randomise off | Выключить случайный порядок |
| Джарвис, включи daylist / дейлист | Запустить сохранённый персональный daylist |
| Джарвис, включи любимые треки | Запустить сохранённую подборку любимых |
| Джарвис, что играет | Назвать трек и исполнителя |
| Джарвис, включи плейлист студия | Запустить заранее сохраненную ссылку «студия» |
| Джарвис, помощь | Услышать основные команды |
| Джарвис, перестань слушать | Завершить Jarvis |

Числа понимаются цифрами и словами. Перемотка — от 1 до 120 секунд. По умолчанию Jarvis ограничивает **запрашиваемую им громкость Spotify** значением 100. Это не ограничитель физической громкости колонок: ручное изменение в Spotify и усилителе этот предел не соблюдает.

Простые команды не озвучиваются, чтобы не мешать музыке. «Что играет» не меняет громкость Spotify. На время голосового ответа распознавание выключается, затем возобновляется. Неизвестные фразы без обращения игнорируются. «Джарвис» — программный фильтр распознанного текста, поэтому слова из музыки тоже теоретически могут вызвать команду.

## Настройки

При первом запуске создается:

`~/Library/Application Support/Jarvis/config.json`

Остановите Jarvis голосом, измените файл и запустите приложение снова. Неуказанные параметры принимают значения по умолчанию. Пример — [config.example.json](config.example.json).

```json
{
  "maximumVolume": 100,
  "volumeStep": 5,
  "spokenFeedback": false,
  "recognitionMode": "automatic",
  "savedMusic": {
    "студия": "https://open.spotify.com/playlist/ВАШ_ID_ИЗ_22_СИМВОЛОВ"
  }
}
```

Замените пример на **настоящую ссылку** Spotify: «Поделиться → Скопировать ссылку на плейлист/трек/альбом». Поддерживаются `https://open.spotify.com/playlist/...`, `/track/...`, `/album/...` и соответствующие `spotify:` URI. Имена задавайте короткие: «студия», «разминка», «вечер». Также допустимы параметры `locale` (по умолчанию `ru-RU`) и `wakeWords` (по умолчанию `["джарвис", "jarvis"]`, каждое имя — одно слово).

**Ограничения прямого управления Spotify:** произвольный поиск по каталогу, добавление в очередь и редактирование очереди не реализованы: этих операций нет в доступном интерфейсе AppleScript установленного Spotify. Команды запуска по имени работают только для сохраненных ссылок. Jarvis не обходит ограничения тарифа и самого Spotify; возможность переключения и запуска ссылок зависит от клиента и аккаунта.

## Распознавание и приватность

Используется встроенный Apple Speech. В режиме `automatic` Jarvis выбирает локальное распознавание, **если Mac сообщает о его поддержке для выбранного языка**. В остальных случаях поток с микрофона обрабатывает сервис Apple, включая речь до слова «Джарвис»; нужен интернет. При старте этот режим озвучивается. Jarvis не сохраняет аудиозаписи и расшифровки и не отправляет аудио в Spotify.

Чтобы запретить сетевое распознавание, установите `"recognitionMode": "onDevice"`. Если выбранный язык/устройство не поддерживает этот режим, Jarvis объяснит причину и завершится. Наличие локального русского распознавания нельзя обещать для любого Mac.

Apple Speech может ограничивать длительность и частоту запросов. Jarvis обновляет сессии каждые 50 секунд, восстанавливается после ошибок с задержкой до 30 секунд, после сна и смены аудиоустройства. Это не гарантирует непрерывную работу облачного распознавания: для постоянной студии сначала проверьте несколько часов с вашим Mac и микрофоном.

## Работа по всей студии

Подробная схема под Mac, iPhone и Windows — [docs/STUDIO.md](docs/STUDIO.md). Для уверенного приема команд при громкой музыке главный фактор — микрофон рядом со ртом, а не мощность компьютера.

## Проверка и разработка

```sh
bash scripts/test-core.sh
bash scripts/build-app.sh
dist/Jarvis.app/Contents/MacOS/Jarvis --check
dist/Jarvis.app/Contents/MacOS/Jarvis --config config.example.json --dry-run 'Джарвис, громкость сорок'
```

`--check` не открывает микрофон и не отправляет команды Spotify. `--dry-run` разбирает фразу и печатает AppleScript без исполнения. Запускайте слушающий режим через `.app`, чтобы разрешения macOS относились к Jarvis.

Архитектура: `JarvisCore` — чистый разбор русских команд, фильтр имени и безопасная генерация AppleScript; `Jarvis` — Apple Speech, аудио и жизненный цикл приложения. Сторонних библиотек и серверов нет. Сборка создается под архитектуру текущего Mac; для другого типа процессора соберите проект на соответствующем Mac.

Локальная сборка подписана ad hoc. Для распространения на другие компьютеры нужна подпись Developer ID и нотариализация Apple; архив из GitHub может вызвать предупреждение Gatekeeper. Не отключайте защиту системы целиком. После изменения подписи/пути macOS иногда требует повторно выдать разрешения.

Источники: [Apple Speech](https://developer.apple.com/documentation/speech/sfspeechrecognizer), [локальное распознавание](https://developer.apple.com/documentation/speech/sfspeechrecognizer/supportsondevicerecognition), [разрешения macOS](https://developer.apple.com/documentation/bundleresources/protected-resources). Команды Spotify сверены с `Spotify.app/Contents/Resources/Spotify.sdef` установленного клиента.

Скрипты сборки не меняют установленный комплект Apple. Если после обновления Command Line Tools остались два объявления SwiftBridging, `scripts/compiler.sh` создает временное представление файлов для компилятора в `.build/`, скрывающее только устаревший дубликат.

## Постоянный фоновый запуск на Mac

```sh
bash scripts/service.sh install
```

Команда устанавливает собранный Jarvis в `~/Applications/Jarvis.app`, регистрирует его в macOS и создает `~/Library/LaunchAgents/com.zusemar.jarvis.plist`. Jarvis запускается сразу и при каждом входе в учетную запись. Служба запускает отдельный помощник JarvisSupervisor, который открывает приложение через LaunchServices: macOS должна относить разрешения к Jarvis.app. После аварийного завершения приложение запускается снова через 30 секунд. При сбое самого помощника его восстанавливает launchd. Для микрофона и Spotify служба работает в графическом сеансе пользователя — [LaunchAgent](https://developer.apple.com/documentation/servicemanagement/).

При первом запуске подтвердите системные запросы доступа. Предыдущая установленная копия приложения и настройки службы при переустановке сохраняются с суффиксом `.backup-...`. Конфигурация музыки остается в `~/Library/Application Support/Jarvis/config.json`.

Управление:

```sh
bash scripts/service.sh status   # состояние фоновой службы
bash scripts/service.sh restart  # перезапустить
bash scripts/service.sh stop     # остановить до следующего входа в macOS
bash scripts/service.sh start    # запустить снова
bash scripts/service.sh disable  # отключить автозапуск и остановить
bash scripts/service.sh check    # диагностика разрешений и журнал
```

Голосовое «Джарвис, перестань слушать» завершает приложение штатно: автоматический перезапуск после этой команды не выполняется. При следующем входе в macOS автозапуск снова сработает. `disable` отключает его до команды `start`. Дополнительная проверка восстановления после сбоя: `bash scripts/service.sh test-restart` (приложение будет аварийно завершено и должно запуститься снова).

Служба не работает до входа в учетную запись и во время сна Mac. После пробуждения приложение восстанавливает прослушивание. Установка не меняет системные настройки сна; для длительной работы от питания настройте их под режим студии. Не добавляйте одновременно вторую копию Jarvis в «Объекты входа».

Технические логи службы: `~/Library/Logs/Jarvis/`. Распознанные фразы в них не записываются.

`~/Library/Application Support/Jarvis/runtime.json` обновляется самим слушающим приложением каждые две секунды и показывает его PID, путь и состояние разрешений. При проверке учитывайте updatedAt: после остановки файл сохраняется. Запуск `--check` или `--execute` из терминала создает другой процесс, разрешения которого могут отличаться от разрешений фонового приложения. После отказа в разрешениях или ошибки первоначального запуска автоматические попытки останавливаются до `start` или следующего входа в macOS.

## Loop, randomise и персональные подборки

`loop` включает **штатный повтор одного трека Spotify**. Он считывает состояние кнопки повтора (0 — выключено, 1 — подборка, 2 — трек) и переключает её до нужного режима. Повторная команда loop выключает уже включённый повтор одного трека. Если повторяется весь плейлист, loop переключает его на повтор одного трека. Явная команда «включи луп» всегда включает повтор трека, «выключи луп» всегда выключает. Для этого выдайте Jarvis разрешение в **Конфиденциальность и безопасность → Универсальный доступ**. Jarvis не нажимает глобальные сочетания клавиш и не переключает фокус на Spotify. Если основное окно Spotify закрыто и кнопка недоступна, команда попросит открыть окно; свёрнутое окно обычно остаётся доступно.

`randomise`/`randomize`/«рандомайз» переключает перемешивание: включает выключенное и выключает включённое. «Включи перемешивание» всегда включает его. Для отключения — `randomise off` или «выключи перемешивание».

«Джарвис, некст», next, skip, «скип» работают как «следующий». «Предыдущий» сначала обнуляет позицию, а затем выбирает предыдущий трек: это обходит стандартное поведение Spotify, когда нажатие Previous посреди песни начинает её заново. Для повторного запуска текущей песни используйте «сначала».

Команды «включи daylist» и «включи любимые треки» используют ссылки из `savedMusic` под ключами `daylist` и `любимые треки`. Ссылки персональные: их нужно один раз скопировать из вашего Spotify. Они хранятся только в локальной конфигурации, в публичный репозиторий не добавляются. Например, подготовьте полный локальный JSON на основе config.example.json, добавьте свои ссылки и примените `bash scripts/service.sh configure config.local.json`, затем `bash scripts/service.sh restart`. Существующие настройки сохраняются в резервную копию перед заменой.

Для проверки команды без микрофона: `bash scripts/service.sh command 'Джарвис, что играет'`. Это выполняет настоящую команду Spotify; тесты через `--dry-run` только показывают её.

## Голос ассистента

Голос и темп задаются в `~/Library/Application Support/Jarvis/config.json`:

```json
{
  "voiceIdentifier": "com.apple.voice.compact.ru-RU.Milena",
  "speechRate": 0.5
}
```

Это два поля внутри вашего существующего JSON; остальные настройки сохраняйте. Пустой voiceIdentifier означает автоматический выбор русского голоса. speechRate допускает 0.25–0.65, по умолчанию 0.5. После изменения перезапустите Jarvis.

Список доступных голосов: `~/Applications/Jarvis.app/Contents/MacOS/Jarvis --list-voices`. Если нужного голоса нет, загрузите его в системных настройках macOS: «Универсальный доступ → Чтение и речь» (в некоторых версиях «Устный контент») → системный голос → управление голосами. Затем снова получите список, укажите идентификатор выбранного голоса и перезапустите Jarvis. Недоступный идентификатор использует автоматический голос.

### Русские команды, английские ответы

Язык распознавания и язык ответов независимы. Для английских ответов установите `"responseLanguage": "en"` и, например, `"voiceIdentifier": "com.apple.voice.compact.en-GB.Daniel"`, сохранив `"locale": "ru-RU"`. Приветствия, справка и ошибки будут английскими; команды останутся русскими, названия музыки сохранят оригинальное написание. Для списка английских голосов: `~/Applications/Jarvis.app/Contents/MacOS/Jarvis --list-voices en`. Для всех языков вместо en укажите all.

Для более естественной бесплатной озвучки загрузите Enhanced/Premium голос Apple и используйте его точный идентификатор из `--list-voices en`. Голоса Siri могут отображаться в системных настройках, но быть недоступны приложениям: [Apple объясняет ограничение AVSpeechSynthesizer](https://developer.apple.com/videos/play/wwdc2020/10022/). Выбор Siri в системных настройках сам по себе не переключает голос Jarvis.

## Бесплатный нейросетевой голос Kokoro

[Kokoro](https://huggingface.co/hexgrad/Kokoro-82M) синтезирует речь на Mac без подписок, API-ключей и отправки текста в облако. Установите Python 3.13, затем выполните `bash scripts/install-kokoro.sh`. Скрипт создаёт отдельное окружение в `~/Library/Application Support/Jarvis/Kokoro/` и загружает модель и голоса проекта [kokoro-onnx](https://github.com/thewh1teagle/kokoro-onnx). Сама загрузка требует интернета; последующее озвучивание работает локально. Модель и голоса занимают около 340 МиБ, окружение требует дополнительного места. Телеметрия ONNX Runtime выключена.

Добавьте в существующие настройки:

```json
{
  "locale": "ru-RU",
  "responseLanguage": "en",
  "speechEngine": "kokoro",
  "kokoroVoice": "af_heart",
  "kokoroSpeed": 1.0
}
```

Остальные поля, особенно savedMusic, сохраните. Перезапустите службу после изменения. Все голосовые ответы, включая приветствие, ошибки и названия треков, будут синтезироваться Kokoro. Русские команды продолжают распознаваться прежним способом. Эта интеграция Kokoro рассчитана на английскую озвучку; русские названия треков могут произноситься неточно. При сбое Kokoro Jarvis записывает ошибку и возобновляет прослушивание, не подменяя выбранный голос системным.

`af_heart` — американский женский голос; также доступны `am_michael` (американский мужской), `bf_emma` (британский женский) и `bm_george` (британский мужской). Скорость kokoroSpeed — 0.5–2.0. Модель остаётся загруженной между ответами, но во время синтеза и воспроизведения распознавание выключено. Временный звуковой файл удаляется после загрузки в проигрыватель. Никаких портов, HTTP-сервера или отдельной страницы нет. Состояние воспроизведения доступно в runtime.json: kokoroCompletedUtterances и kokoroLastError.

После сборки выполните `python3 scripts/prepare-kokoro.py`: приветствие, справка и остальные постоянные английские реплики будут синтезированы заранее. Они хранятся в Kokoro/phrases. При запуске реплики доступны сразу, а модель загружается в фоне. Последние 24 динамических ответа кэшируются только в памяти процесса; названия треков на диске не сохраняются. В локальном тесте выдача готового приветствия заняла около 0.17 секунды; задержка новых названий зависит от длины текста, прогрева модели и загрузки Mac.

Словарь pronunciations исправляет необычное написание артистов перед синтезом. По умолчанию A$AP Rocky превращается в Ay-sap Rocky; его LVL — в Level. Можно добавить свои пары, например `"The Weeknd": "The Weekend"`. Это меняет только озвучку, не названия в Spotify.

Чтобы вернуться к голосам macOS, установите `"speechEngine": "apple"`. Параметры voiceIdentifier и speechRate действуют только для системной озвучки; для Kokoro используются kokoroVoice и kokoroSpeed.

## OpenClaw для свободных формулировок

Прямые команды всегда разбираются локально. Если установлено `"intentEngine": "openclaw"`, непонятная фраза после обращения «Джарвис» передаётся отдельному агенту jarvis. Без обращения облако не вызывается. Модель возвращает одну команду из ограниченного набора; произвольные действия, неизвестные плейлисты и составные команды не выполняются. При ошибке или таймауте Jarvis возобновляет прослушивание.

Требуется установленный OpenClaw в /usr/local/bin/openclaw и существующий профиль OpenRouter. Создайте агента и настройте его:

```sh
openclaw agents add jarvis --non-interactive --workspace "$HOME/Library/Application Support/Jarvis/OpenClaw" --model openrouter/poolside/laguna-xs-2.1:free
python3 scripts/configure-openclaw.py
```

Скрипт меняет только агента jarvis и параметры используемой им модели, сохраняет предыдущий конфиг и повторно использует существующее разрешение OpenRouter для того же провайдера. Основной агент и его маршрутизация сохраняются. У классификатора отключены инструменты, навыки и платные резервные модели. Это отдельный служебный агент без переписки с контактами. Его история очищается перед каждым запросом и после завершения; не используйте его как обычный чат.

Выбран бесплатный облачный Laguna XS 2.1. Модель не загружается в память Mac, но OpenClaw запускает небольшой локальный процесс на время запроса. Непонятная текстовая команда отправляется OpenRouter и провайдеру модели; их условия обработки данных продолжают действовать. Обычные команды и текст озвучки Kokoro туда не передаются. Бесплатные модели имеют очереди, ограничения запросов и могут быть временно недоступны. Для разборов выделено до 25 секунд; это не задерживает прямые команды при обычном прослушивании, но на время одного облачного разбора микрофон закрыт. Для проверки без управления Spotify: `Jarvis.app/Contents/MacOS/Jarvis --interpret 'Верни прошлую песню'`.

После локальной ad hoc сборки macOS может продолжать показывать старую запись Jarvis в «Универсальном доступе», хотя новая копия приложения не считается доверенной. В этом случае удалите старую запись и добавьте текущий `~/Applications/Jarvis.app` заново. Затем повторите loop. Установка не изменяет базу разрешений macOS и не обходит проверку доступа.
